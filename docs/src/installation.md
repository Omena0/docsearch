# Installation

## Prerequisites

- Python >= 3.10
- pip

## Install from PyPI

```bash
pip install fr-docs
```

## Install from Source

```bash
git clone https://github.com/Omena0/fr-docs.git
cd fr-docs
pip install -e .
```

## Project Setup

1. Create a `config.json` in `docs/`
2. Add your documentation markdown files in `docs/src/`
3. Run `fr-docs build`
4. Serve files in `docs/site/`
